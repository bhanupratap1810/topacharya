# TopAcharya

TopAcharya is a modern, responsive mentorship platform inspired by the ancient **Guru–Shishya tradition**.
It is designed to connect ambitious learners with experienced mentors (Acharyas) who have mastered their craft and can provide real, guided growth.

The platform focuses on clarity, simplicity, and trust, offering a clean user experience across all devices.

---

## 🌟 Features

* Fully responsive design (desktop, tablet, mobile)
* Clean, modern UI with a consistent design system
* Mentor discovery with profile cards and ratings
* Dedicated pages for:

  * Home
  * Find Mentors
  * About Us
  * Contact Us
* Scalable structure ready for future features:

  * Mentor profiles
  * Booking & scheduling
  * Payments
  * Authentication
* Optimized for GitHub Pages deployment

---

## 🛠 Tech Stack

* **HTML5** – Semantic, accessible markup
* **CSS3** – Custom design system with responsive layouts
* **Font Awesome** – Icons
* **GitHub Pages** – Hosting & deployment

No frameworks or heavy dependencies are used, keeping the project fast, lightweight, and easy to maintain.

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/your-username/topacharya.git
```

### 2. Open locally

Simply open `index.html` in your browser, or use a local server for best results.

### 3. Deploy on GitHub Pages

1. Push the project to a GitHub repository
2. Go to **Settings → Pages**
3. Select branch `main` and root directory
4. Save and access your live site
